    The city is backed by a real k3d Kubernetes cluster. The bank (payments-api) really crashes: a memory limit too small for the cache it allocates, so the container is OOMKilled for real, over and over. An AI agent investigates with read-only tools, raises the limit with the single write tool it has, and verifies the recovery. Smoke, log bubbles, the repair sprite, the dawn — every one of them is driven by an event in the agent's trace. No event, no pixels.
